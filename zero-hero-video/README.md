# zero-hero-video

Claude Code plugin for making **ZERO** videos: short vertical reels where Zero, an AI hero, lives inside a trade company's brand and takes
over the calls the owner keeps missing. Built for Apex Zero Studio.

- `skills/zero-hero-video/SKILL.md`: how Claude runs the workflow, plus the lessons learned building the first reels.
- `template/`: the renderer (`render.py`), example briefs, sound effects, voice lines, logo files and brand book.

Quick start: `cd template && python3 render.py briefs/apex_zero_electrician.json --preview`.
Third-party content: sound effects were rendered from the earshot sound bank (MIT); voice lines were generated on Higgsfield.
